# ETA 2824-2 自动机芯 · 齿轮系拆解（Caliber Explorer）

瑞士 **ETA 2824-2** 自动上链机芯的参数化教学复刻，使用纯 **Three.js**、零依赖外链构建，赛博朋克 HUD 风格。

> ⚠️ **免责声明**：本项目是个人学习用途的**独立参数化复刻**，与 ETA SA / Swatch Group 无任何关联、赞助或认证关系，"ETA 2824-2" 名称仅用于指称被复刻的机芯型号。几何为程序化示意建模，非原厂工程图纸，尺寸不代表真实公差。

## ✨ 功能特性

- **15 个机芯组件**：主夹板、三块桥板、25 钻宝石轴承、发条盒、四级传动轮系、擒纵轮、擒纵叉、摆轮、游丝，以及 2824-2 标志性的**双向滚珠轴承自动陀**与**换向轮组**，全部程序化建模。
- **真实齿数的运转轮系**：传动链以单一数据源驱动——轴距按分度圆半径计算，角速度沿链递推（啮合反向、同轴同速），摆轮/游丝/擒纵叉同频摆动。
- **轴向爆炸拆解**：15 个组件沿轮轴方向（Z 轴）分层展开，可单独收起任意部件。
- **智能点选与聚焦**：点击模型或左侧清单，自动高亮、平滑聚焦，右侧展示齿数、齿轴、传动比、原厂件号与材质规格。
- **可暂停的机械律动**：底部「暂停运转」冻结整个轮系，方便静态观察啮合关系。

## ⚙️ 轮系齿数与运动学闭合

ETA 不公开官方齿数表，模型采用由官方摆频与各级转速约束**反推复原**的齿数链：

```
条盒轮(96T) → 中心轮(80T/12叶) → 过轮(75T/10叶) → 秒轮(72T/10叶) → 擒纵轮(20T/6叶)
```

| 级别 | 传动比 | 从动轮转速 |
|---|---|---|
| 条盒 → 中心 | 96 / 12 = 8 : 1 | 中心轮 1 r/h（条盒 0.125 r/h，约 8 h/圈） |
| 中心 → 过轮 | 80 / 10 = 8 : 1 | 过轮 8 r/h |
| 过轮 → 秒轮 | 75 / 10 = 7.5 : 1 | 秒轮 60 r/h（1 r/min） |
| 秒轮 → 擒纵 | 72 / 6 = 12 : 1 | 擒纵轮 720 r/h |

**摆频校验**：720 r/h × 2（每齿两次锁接）× 20 齿 = **28,800 vph**，与官方规格严格闭合。中心轮到擒纵轮总增速 = 8 × 7.5 × 12 = **720 : 1**。

演示时对高速级角速度做了非线性压缩（指数 0.42），仅压缩速率、不改变转向与层级关系，避免高速齿轮视觉频闪。

## 🚀 如何在本地运行

原生 ES 模块，请勿直接双击打开 `index.html`。在项目根目录启动静态服务器：

```bash
python3 -m http.server 8080
# 或
npx serve .
```

浏览器打开 `http://localhost:8080`。
