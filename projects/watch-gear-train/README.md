# 机械手表 · 齿轮系拆解（Gear Train Explorer）

一个使用纯 **Three.js**、零依赖外链构建的交互式机械手表机芯爆炸图，复刻赛博朋克 HUD 科技风。

## ✨ 功能特性

- **13 个机芯组件**：主夹板、三块桥板、红宝石轴承、发条盒、四级传动轮系、擒纵轮、擒纵叉、摆轮与游丝，全部程序化建模。
- **真实啮合的运转轮系**：传动链以单一数据源驱动——轴距按分度圆半径计算，角速度沿链递推（啮合反向、同轴同速），摆轮/游丝/擒纵叉以 4 Hz 同频摆动。
- **轴向爆炸拆解**：点击「全部拆解」或拖动滑块，13 个组件沿轮轴方向（Z 轴）分层展开，并可单独收起任意部件。
- **智能点选与聚焦**：点击 3D 模型或左侧清单中的部件，自动高亮、平滑聚焦，右侧实时展示齿数、齿轴、传动比与材质规格。
- **可暂停的机械律动**：底部「暂停运转」可冻结整个轮系，方便静态观察啮合关系。
- **纯粹的赛博 HUD 视觉**：悬浮标签、虚线引线、雷达刻度环、星点、扫描线、实时 FPS 与模式仪表。
- **极致可移植性**：不使用任何外部 CDN（Three.js 已内置于 `vendor/` 目录），克隆即可在任何地方运行。

## ⚙️ 传动链说明

```
条盒轮(72T) → 中心轮(64T/12齿轴) → 过轮(48T/10齿轴) → 秒轮(40T/10齿轴) → 擒纵轮(30T/8齿轴)
```

- 轴距 = 主动轮分度圆半径 + 从动齿轴分度圆半径（模数 m = 0.10 场景单位）
- 角速度：`ω从动 = -ω主动 × (z主动 / z从动齿轴)`，总传动比 = 6 × 6.4 × 4.8 × 5 ≈ **921.6 : 1**
- 演示时对高速级角速度做了非线性压缩（指数 0.42），仅压缩速率、不改变转向与层级关系，避免高速齿轮视觉频闪

## 🚀 如何在本地运行

因为使用了原生 ES 模块，请不要直接双击打开 `index.html`（浏览器会拦截本地模块加载）。
在项目根目录下启动一个静态文件服务器即可：

```bash
python3 -m http.server 8080
# 或
npx serve .
```

然后在浏览器中打开：`http://localhost:8080`
